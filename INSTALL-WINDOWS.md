# Phasekick for Windows 11

1. Open the Actions tab in this repository.
2. Select Build Phasekick Windows VST3 and view the latest run. If necessary click Run workflow.
3. Once the build succeeds, download the Phasekick-Windows11-VST3 artifact.
4. Extract the ZIP. Copy the entire Phasekick.vst3 folder to C:\Program Files\Common Files\VST3\.
5. Restart Ableton Live 12 and insert Phasekick from the VST3 plugins list on a MIDI track.
6. Optional: run Phasekick.exe as a standalone instrument.

The first Windows build has not yet been verified. If a run fails, open the failed step and inspect the log.
